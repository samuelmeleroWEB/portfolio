# Samuel Melero - Portfolio Personal

Bienvenido al repositorio de mi portafolio personal. Este proyecto digital sirve como mi carta de presentación, donde muestro mi experiencia, habilidades como Desarrollador Full Stack y los proyectos más destacados en los que he trabajado.

## 🚀 Tecnologías Utilizadas

Este proyecto ha sido desarrollado siguiendo las mejores prácticas y utilizando un stack tecnológico moderno:

- **React 18** - Biblioteca principal para la interfaz de usuario.
- **TypeScript** - Tipado estático para un código más robusto y mantenible.
- **Vite** - Herramienta de compilación ultrarrápida.
- **Framer Motion** - Para crear animaciones fluidas y complejas.
- **SCSS Modules** - Estilado modular, encapsulado y escalable.
- **GitFlow** - Metodología de control de versiones para organizar el desarrollo.

## 🎯 Características Principales

- **Diseño Terminal Futurista**: Interfaz única, oscura y profesional inspirada en el aspecto de una terminal y en las estética cyberpunk/editorial, con un color de acento altamente contrastante (verde neón).
- **Animaciones Suaves y Fluídas**: Construidas con `framer-motion` y adaptadas a la interacción del usuario.
- **Proyectos Dinámicos**: Tarjetas de proyectos interactivas, con indicadores dinámicos (badges) y enlaces a repositorios y demostraciones en vivo.
- **Secciones Adaptativas**: Experiencia optimizada para móviles (Responsive Design).
- **Favicon Personalizado**: Logotipo vectorial para la cabecera.

## 🛠 Instalación y Uso Local

Para ejecutar este proyecto en tu entorno local, sigue los siguientes pasos:

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/samuelmeleroWEB/portfolio.git
   ```

2. **Navegar al directorio:**
   ```bash
   cd portfolio
   ```

3. **Instalar dependencias:**
   ```bash
   npm install
   ```

4. **Iniciar el servidor de desarrollo:**
   ```bash
   npm run dev
   ```

5. **Abrir en el navegador:**
   La aplicación se abrirá por defecto en `http://localhost:5173`.
